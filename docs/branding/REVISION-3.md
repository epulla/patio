# Patio artwork — revision 3

The paper airplane, hand, wrist, and local forearm were redrawn together in the logo and social graphic. The replacement uses a side view, visible folded paper surfaces, and fingers overlapping the folded body. This replaces the earlier upright-thumb pose.

The approved app icon and every native icon export are preserved without re-encoding or modification. The smooth plum wordmark remains the lettering treatment.

## Pose reference

The central hand-and-paper-plane pose in [Alexander Lesnitsky / AlLes’s photograph on Pixabay](https://pixabay.com/photos/hands-wrist-hand-fingers-boomerang-4632734/) was used as a visual guide. Only that central pose was relevant; the other objects were ignored. The photographic image is not redistributed in this kit. The actual assets were edited with the built-in image-generation tool in the existing cartoon/crayon style.
